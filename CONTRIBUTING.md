# Участь у розробці

Перед початком роботи прочитайте README.md.
Помилки та пропозиції можна обговорити через Issues.

## Як внести зміни

1. Створіть копію репозиторію кнопкою Fork.
2. Завантажте свою копію на комп'ютер.
3. Створіть окрему гілку від актуальної main:

```bash
git checkout main
git pull
git checkout -b feature/new-feature
```

Для виправлення помилок використовуйте назви на зразок
fix/balance-calculation, для нових можливостей - feature/new-feature.

4. Внесіть зміни, дотримуючись стилю наявного коду.
5. Перевірте збірку та запустіть тести з папки, де розташований TrackMyCash.sln:

```bash
dotnet build TrackMyCash.sln
dotnet test TrackMyCash.sln
```

Якщо змінюєте логіку обчислень, додайте або оновіть відповідні тести.
Вручну перевірте змінені функції. Для роботи з транзакціями
перевірте додавання доходу, додавання витрати та оновлення балансу.

6. Збережіть зміни та завантажте гілку у свою копію репозиторію:

```bash
git add .
git commit -m "Describe changes"
git push -u origin feature/new-feature
```

У командах використовуйте назву своєї гілки.
Перед commit перевірте, які файли додаєте.

## Оформлення Pull Request

На GitHub відкрийте Pull Request зі своєї гілки
до гілки main початкового репозиторію.

У заголовку коротко вкажіть суть змін.
В описі поясніть, що змінено, навіщо та як це перевірено.
Якщо є пов'язане Issue, додайте посилання на нього.
Для змін інтерфейсу додайте скріншот.

Не додавайте паролі, особисті фінансові дані,
локальні бази даних і папки bin та obj.
Дочекайтеся перевірки Pull Request учасниками команди.
